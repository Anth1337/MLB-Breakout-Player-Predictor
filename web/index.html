    How the board was built

    The label

    A minor-league season counts as a breakout if that hitter went on to take 500 or more major-league plate appearances with an OPS of .740 or better within the next six seasons — roughly the bar for an above-average everyday regular. Across 13,469 prospect-aged seasons from 2008–2018, 5.5% cleared it.

    The model

    Logistic regression on fifteen features, chosen over a random forest and gradient boosting on validation PR-AUC. Splits are by season, never random: train through 2016, validate on 2017, test on a locked-away 2018. The strongest signals are age, level reached, OPS, and age relative to the level's average — a 19-year-old holding his own in Double-A is the textbook profile.

    Reading the score

    The score ranks, it does not forecast. All three models use class_weight="balanced", which inflates predicted probabilities against a 5.5% base rate — the calibration curve has the .90-and-up bucket converting at closer to .60. Treat a .99 as "top of the board," not as a 99% chance.

    The chips under each hitter are that player's three largest SHAP contributions: an up arrow means the feature pushed his score up, a down arrow means it pulled the score down, with the feature's actual value alongside.

    What it can't see

    No Statcast. The MLB Stats API exposes traditional minor-league lines only, so exit velocity, barrel rate and expected wOBA are all missing — the quality-of-contact data that would sharpen Triple-A reads most. Defensive value is absent too: position is carried for display but never fed to the model.
